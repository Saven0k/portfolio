# Ручная проверка формы связи

Запустите `npm run dev` и откройте `http://127.0.0.1:3000/portfolio/tests/contact-form.html`. Если Vite выбрал другой порт, возьмите его из вывода команды.

Страница отображает настоящий компонент формы. `fetch` перехвачен до его импорта: реальные запросы не уходят, неожиданные запросы блокируются. Кнопки «Ответить успешно» и «Ответить с ошибкой» вручную завершают текущий запрос. В статусе видны количество запросов, ожидание ответа и отправленные поля.

1. Заполните все поля, отправьте форму и нажмите «Ответить с ошибкой». Уведомление об ошибке должно появиться, введённые данные — сохраниться.
2. Повторно отправьте форму до истечения 3 секунд после ошибки. Оставьте запрос без ответа более 3 секунд: поля и кнопка отправки должны оставаться заблокированными, индикатор загрузки — видимым. Затем ответьте успешно: поля должны очиститься.
3. Снова заполните и отправьте форму, ответьте успешно. Две успешные отправки подряд должны каждый раз очищать поля и показывать уведомление.
4. Сразу после успеха начните вводить новый черновик, не отправляя его. Через 3 секунды уведомление должно скрыться, а черновик — сохраниться.

Проверка не подтверждает доставку сообщений реальным сервисом Formspree.
